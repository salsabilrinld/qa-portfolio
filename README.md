## 🔍 Ringkasan Project

### 1. 📋 [Test Plan — E-Commerce Login](./test-plans/test-plan-ecommerce-login.md)
Dokumen test plan lengkap untuk modul login aplikasi e-commerce, mencakup scope, strategi pengujian, jadwal, entry/exit criteria, dan risk assessment.

### 2. 🧾 [Test Cases — Login (Equivalence Partitioning)](./test-cases/TC-login-equivalence-partitioning.md)
Test case untuk halaman login menggunakan teknik **Equivalence Partitioning** — format tabel yang sama seperti dokumentasi testing profesional.

### 3. 🧾 [Test Cases — Register (Boundary Value Analysis)](./test-cases/TC-register-boundary-value.md)
Test case untuk form registrasi menggunakan teknik **Boundary Value Analysis** untuk validasi input field.

### 4. 🐛 [Bug Reports](./bug-reports/)
Contoh laporan bug dengan format standar industri: steps to reproduce, expected vs actual result, severity, priority, dan screenshot.

Test case untuk REST API endpoint menggunakan Postman — validasi status code, response body, dan error handling.

Script dasar Selenium + Python untuk menunjukkan pemahaman tentang test automation.
